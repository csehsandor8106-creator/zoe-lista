ZOÉ LISTA – PWA

Ez egy statikus, telepíthető Progressive Web App.
A lista, saját árak és tanult termékfelismerések a böngésző helyi tárhelyén maradnak.
A PWA telepítéséhez HTTPS alatt kell kiszolgálni (pl. GitHub Pages, Cloudflare Pages, Netlify).

Fő funkciók:
- üres listával indul
- természetes nyelvű termékbevitel
- mennyiség a név előtt vagy után
- termék- és márkafelismerés
- óvatos fuzzy matching
- automatikus kategória és ikon
- automatikus becsült ár
- saját ár megjegyzése
- kipipálás, mennyiség +/- és törlés
- kézi szerkesztés + tanuló felismerés
- kategóriás csoportosítás
- teljes összeg
- offline cache
- sötét/világos mód
